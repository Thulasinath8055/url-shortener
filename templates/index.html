JWT Authentication

Stateless, scalable token-based auth using Simple JWT with secure password hashing.

High Performance

Atomic click counting with F() expressions. Indexed short codes for O(log n) lookups.

Auto Documentation

Interactive Swagger UI generated automatically from DRF serializers and views.

API Endpoints

RESTful API with JSON responses

Method Endpoint Auth Description
POST /api/register/ None Create new account
POST /api/login/ None Obtain JWT tokens
GET /api/urls/ JWT List user's URLs
POST /api/urls/ JWT Create short URL
DELETE /api/urls/<id>/ JWT Delete a URL
GET /<short_code>/ None Redirect to original URL

Built with Django 5 & Django REST Framework. Open source on GitHub.
